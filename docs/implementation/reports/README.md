# docs/implementation/reports/

Informes históricos de entrega de cada etapa (dictámenes, resultados de pruebas, estado de Git al cierre).

- Son **evidencia**, no instrucciones: no copiar su contenido íntegramente en prompts ni tratarlos como specs vigentes.
- **No reescribir** informes ya emitidos; corregir un hecho posterior se hace en `IMPLEMENTATION_STATUS.md`.
- El estado actual del proyecto siempre está en `../IMPLEMENTATION_STATUS.md`.
